# TBHUB

The hub for an interactive textbook family:

- [CppTB](https://github.com/Abiel990310/CppTB) — C++
- [JavaTB](https://github.com/Abiel990310/JavaTB) — Java
- [CsaTB](https://github.com/Abiel990310/CsaTB) — AP Computer Science A
- [CalTB](https://github.com/Abiel990310/CalTB) — AP Calculus AB/BC
- [PhysTB](https://github.com/Abiel990310/PhysTB) — AP Physics C

A landing page and a stats page. The statistics are read from each book's own
published data rather than typed here, so they cannot drift out of date.

> The AP books are **not official College Board products**. AP® is a trademark
> of the College Board, which does not endorse and is not involved with them.
